# Zombi Gazabı

A fast-paced 2D top-down zombie survival shooter built in Unity.
Made by **TLCC Studio** (Tomorrow's Legends Creative Collective).

> Work in progress. My first game, built to learn game development.

## Gameplay

Survive as long as you can against endless zombies. Aim with the mouse,
shoot lasers, and see how long you last.

## Features

- Mouse-aimed shooting with gun recoil and laser bullets with trail effects
- Zombie AI with chase and spawn logic
- Player health, knockback and invincibility frames
- Game feel: screen shake, hit-stop, hit flash, squash and stretch
- Survival timer and Game Over screen with restart
- Animated player walk cycle

## Controls

| Input | Action |
|---|---|
| WASD | Move |
| Mouse | Aim |
| Left click | Shoot |
